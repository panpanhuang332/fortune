# 測字塔羅合參

寫一個字、抽三張塔羅牌，以拆字、梅花測字起卦與五行體用合參，產出吉凶斷語與逐項計分帳。

線上使用：https://panpanhuang332.github.io/fortune/

- 拆字：依漢字構形描述序列（IDS）拆解部件，看結構與部件象義、五行生剋
- 梅花測字起卦：以左右／上下筆畫或全字筆畫加時辰起本卦、互卦、變卦，定體用
- 塔羅：78 張牌正逆位，四花色與大牌對應五行，與體卦比生剋
- 合參帳：每一筆加減分逐項列出

單一 HTML 檔，下載後雙擊即可離線使用。

字形資料來源：CHISE IDS / cjkvi-ids、Make Me a Hanzi（筆畫數）。
